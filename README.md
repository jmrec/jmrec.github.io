# jmrec.github.io

The landing page at [docs.jmrecondo.com](https://docs.jmrecondo.com), linking to the documentation for the tools I build.

It is plain HTML and CSS in `site/`, with no build step. Each project's docs are a separate site, deployed from that project's own repository.

The earlier Astro Starlight version is kept on the `astro` branch.
